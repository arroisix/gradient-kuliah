# Gradient Web

Main Gradient Web Platform repository

## Prerequisites

-   please prepare your package manager such as npm/yarn/pnpm(recommended)

## Getting Started

Install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `src/pages/index.ts`. The page auto-updates as you edit the file.
